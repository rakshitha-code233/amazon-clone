# Amazon Clone 🛒

## About the Project
This project is a simple Amazon Clone created to practice frontend web development. It recreates the basic look and layout of the Amazon website.

## Technologies Used
- HTML5
- CSS3

## Features
- Amazon-inspired user interface
- Navigation bar and search bar
- Product display section
- Responsive styling (if implemented)

## How to Run
1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

## Project Purpose
This project was developed for learning and practicing HTML and CSS.
